# Blog Outline — SEO Structure

**When to use:** planning an article that answers the searcher's question fully.

## Prompt — copy, replace [BRACKETS], paste into Muse.ai

```
Create an SEO outline for [KEYWORD/TOPIC]: H1, 5-7 H2s in searcher order, 2-3 bullet points under each, a FAQ section answering People-Also-Ask-style questions, and an internal-link suggestion list. Audience: [AUDIENCE].
```

## Good output looks like

- H1 → H2s → bullets → FAQ → internal links

## Tips
- Replace every [BRACKET] before you run it — leftovers leak into the output.
- Ask for a shorter version first if the first draft rambles, then expand only the best section.
- Check facts, prices, and claims yourself before publishing. Muse.ai drafts; you verify.
