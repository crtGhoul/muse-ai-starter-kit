# Meta Tags Optimizer

**When to use:** titles and descriptions that earn clicks without clickbait.

## Prompt — copy, replace [BRACKETS], paste into Muse.ai

```
Write 5 title tags (under 60 chars) and 5 meta descriptions (under 155 chars) for [PAGE/TOPIC] targeting [KEYWORD]. Each must accurately describe the page — no promise the page doesn't keep.
```

## Good output looks like

- 5 titles + 5 descriptions, with character counts

## Tips
- Replace every [BRACKET] before you run it — leftovers leak into the output.
- Ask for a shorter version first if the first draft rambles, then expand only the best section.
- Check facts, prices, and claims yourself before publishing. Muse.ai drafts; you verify.
