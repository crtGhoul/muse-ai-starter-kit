# Keyword Research

**When to use:** finding long-tail keywords for a new article or page.

## Prompt — copy, replace [BRACKETS], paste into Muse.ai

```
Generate 30 long-tail keyword ideas for [TOPIC/AUDIENCE], grouped by intent: informational (15), commercial (10), transactional (5). For each, note why a reader would search it. Do not invent search volumes — mark volume as 'check in your SEO tool'.
```

## Good output looks like

- 3 intent groups, no invented volume numbers

## Tips
- Replace every [BRACKET] before you run it — leftovers leak into the output.
- Ask for a shorter version first if the first draft rambles, then expand only the best section.
- Check facts, prices, and claims yourself before publishing. Muse.ai drafts; you verify.
