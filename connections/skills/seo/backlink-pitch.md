# Backlink / Guest Post Pitch

**When to use:** outreach that a site owner might actually answer.

## Prompt — copy, replace [BRACKETS], paste into Muse.ai

```
Write a short guest-post pitch email to [SITE/EDITOR] proposing [TOPIC] for their audience of [AUDIENCE]. Lead with what's in it for their readers, include 3 headline options and one relevant sample (link or paste). Keep it under 150 words. No flattery templates, no mass-mail tone.
```

## Good output looks like

- Subject + under-150-word body + 3 headlines

## Tips
- Replace every [BRACKET] before you run it — leftovers leak into the output.
- Ask for a shorter version first if the first draft rambles, then expand only the best section.
- Check facts, prices, and claims yourself before publishing. Muse.ai drafts; you verify.
