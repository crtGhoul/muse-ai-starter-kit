# Email Sequence (5 emails)

**When to use:** nurturing new subscribers toward a first purchase or signup.

## Prompt — copy, replace [BRACKETS], paste into Muse.ai

```
Write a 5-email nurture sequence for [PRODUCT/AUDIENCE]. Email 1: welcome + quick win. Email 2: story/problem. Email 3: how it works. Email 4: objections answered. Email 5: offer + deadline (only if the deadline is real). Each email: subject line under 50 chars, one idea, one CTA. Tone: [TONE].
```

## Good output looks like

- 5 emails, each with subject + body + CTA
- No invented deadlines or fake scarcity

## Tips
- Replace every [BRACKET] before you run it — leftovers leak into the output.
- Ask for a shorter version first if the first draft rambles, then expand only the best section.
- Check facts, prices, and claims yourself before publishing. Muse.ai drafts; you verify.
