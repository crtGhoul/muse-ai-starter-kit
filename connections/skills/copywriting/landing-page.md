# Landing Page

**When to use:** a single page with one job: get the click or signup.

## Prompt — copy, replace [BRACKETS], paste into Muse.ai

```
Write a landing page for [PRODUCT]. Sections: hero headline (outcome in under 12 words), subhead, 3 feature bullets, how-it-works in 3 steps, FAQ (3 questions), final CTA. Audience: [AUDIENCE]. Objection to answer: [OBJECTION].
```

## Good output looks like

- Hero, features, how-it-works, FAQ, CTA — in that order

## Tips
- Replace every [BRACKET] before you run it — leftovers leak into the output.
- Ask for a shorter version first if the first draft rambles, then expand only the best section.
- Check facts, prices, and claims yourself before publishing. Muse.ai drafts; you verify.
