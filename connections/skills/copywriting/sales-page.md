# Sales Page

**When to use:** a product or service landing page that needs to convert visitors, not just inform them.

## Prompt — copy, replace [BRACKETS], paste into Muse.ai

```
Write a high-converting sales page for [PRODUCT] aimed at [AUDIENCE]. Include: a headline that names the outcome, a subhead that removes the main objection, 3 benefits (not features), social proof section (use only real quotes you supply below), pricing, guarantee, and one clear call-to-action. Tone: [TONE]. Real proof I can use: [PASTE REAL TESTIMONIALS OR 'none — write without fake proof'].
```

## Good output looks like

- Headline + subhead
- Problem → solution
- 3 benefits
- Proof (real only)
- Price, guarantee, CTA

## Tips
- Replace every [BRACKET] before you run it — leftovers leak into the output.
- Ask for a shorter version first if the first draft rambles, then expand only the best section.
- Check facts, prices, and claims yourself before publishing. Muse.ai drafts; you verify.
