# CTA Buttons — 50 variations

**When to use:** when 'Learn more' is doing nothing for your page.

## Prompt — copy, replace [BRACKETS], paste into Muse.ai

```
Give me 50 call-to-action button labels for [PRODUCT/ACTION], grouped as: direct (10), benefit-led (10), low-commitment (10), curiosity (10), urgency — only where the urgency is real (10). Each under 5 words. Avoid clickbait that the page can't deliver.
```

## Good output looks like

- 5 groups of 10, each labelled, each under 5 words

## Tips
- Replace every [BRACKET] before you run it — leftovers leak into the output.
- Ask for a shorter version first if the first draft rambles, then expand only the best section.
- Check facts, prices, and claims yourself before publishing. Muse.ai drafts; you verify.
