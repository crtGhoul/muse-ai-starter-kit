# API Documentation

**When to use:** documenting a REST API so another developer can use it without asking you questions.

## Prompt — copy, replace [BRACKETS], paste into Muse.ai

```
Write REST API docs for [ENDPOINT]. Include: purpose, method + path, auth, request example, response example, error codes, and rate limits. If any detail is unknown, mark it TODO instead of guessing. Base URL: [URL].
```

## Good output looks like

- Endpoint card, examples, errors, TODOs where unknown

## Tips
- Replace every [BRACKET] before you run it — leftovers leak into the output.
- Ask for a shorter version first if the first draft rambles, then expand only the best section.
- Check facts, prices, and claims yourself before publishing. Muse.ai drafts; you verify.
