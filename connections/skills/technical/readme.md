# README

**When to use:** open-source projects that need a README people actually read.

## Prompt — copy, replace [BRACKETS], paste into Muse.ai

```
Write a README for [PROJECT]: what it does in one sentence, who it's for, quickstart (copy-paste commands), features, configuration, contributing, license. Keep it under 600 words. Repo: [URL].
```

## Good output looks like

- One-sentence pitch → quickstart → features → contributing

## Tips
- Replace every [BRACKET] before you run it — leftovers leak into the output.
- Ask for a shorter version first if the first draft rambles, then expand only the best section.
- Check facts, prices, and claims yourself before publishing. Muse.ai drafts; you verify.
