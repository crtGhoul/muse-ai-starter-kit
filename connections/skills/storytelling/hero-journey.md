# Hero's Journey

**When to use:** brand stories, about pages, and launch posts that need a narrative arc.

## Prompt — copy, replace [BRACKETS], paste into Muse.ai

```
Tell the story of [PERSON/BRAND] using the Hero's Journey: ordinary world, call to adventure, struggle, mentor/tool, turning point, return with a lesson. Keep it under 400 words, specific details only — no invented events. Facts I can use: [FACTS].
```

## Good output looks like

- 6 beats, in order, ending on a usable lesson — not a sales pitch

## Tips
- Replace every [BRACKET] before you run it — leftovers leak into the output.
- Ask for a shorter version first if the first draft rambles, then expand only the best section.
- Check facts, prices, and claims yourself before publishing. Muse.ai drafts; you verify.
