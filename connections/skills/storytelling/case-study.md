# Case Study — Before / After

**When to use:** showing a real transformation with evidence.

## Prompt — copy, replace [BRACKETS], paste into Muse.ai

```
Write a case study from these facts only: Before: [SITUATION + METRICS]. What changed: [ACTIONS]. After: [METRICS + TIMEFRAME]. Include what didn't work, not just the win. If a metric is missing, write '[metric not measured]' instead of inventing one.
```

## Good output looks like

- Before / actions / after / what didn't work / lesson

## Tips
- Replace every [BRACKET] before you run it — leftovers leak into the output.
- Ask for a shorter version first if the first draft rambles, then expand only the best section.
- Check facts, prices, and claims yourself before publishing. Muse.ai drafts; you verify.
