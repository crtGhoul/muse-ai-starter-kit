# Testimonial Template — REAL testimonials only

**When to use:** collecting and presenting customer proof honestly.

## Prompt — copy, replace [BRACKETS], paste into Muse.ai

```
Turn this real customer feedback into a short testimonial, keeping their exact meaning and only editing for grammar/length. Do NOT invent names, companies, results, or quotes. If a result is claimed, keep the evidence alongside it.

IMPORTANT: Never publish a testimonial you invented. This template replaces any 'fake but realistic' approach — fake proof destroys trust and can violate advertising rules.

Real feedback: [PASTE VERBATIM FEEDBACK + PERMISSION STATUS].
```

## Good output looks like

- Quote (verbatim meaning) + name + role + permission noted
- Result claim only with evidence attached

## Tips
- Replace every [BRACKET] before you run it — leftovers leak into the output.
- Ask for a shorter version first if the first draft rambles, then expand only the best section.
- Check facts, prices, and claims yourself before publishing. Muse.ai drafts; you verify.

> Referral note: this file deliberately contains no referral pitch — proof must stay clean and real.
