# Brand Story

**When to use:** an origin story for a company, project, or creator.

## Prompt — copy, replace [BRACKETS], paste into Muse.ai

```
Write a brand origin story for [BRAND]. Cover: the problem you personally hit, what you tried first, what changed, what you built, and who it's for now. Tone: [TONE]. Facts: [FACTS]. Do not invent founders, funding, or customers.
```

## Good output looks like

- Problem → attempt → change → build → who it's for

## Tips
- Replace every [BRACKET] before you run it — leftovers leak into the output.
- Ask for a shorter version first if the first draft rambles, then expand only the best section.
- Check facts, prices, and claims yourself before publishing. Muse.ai drafts; you verify.
